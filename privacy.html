Privacy policy

Hermes Agent is a personal, self-hosted assistant used only by its owner. There are no other users.

What data it accesses

With the owner's consent it accesses the owner's own Google account data (Gmail, Google Calendar, Google Drive, Docs, Sheets and contacts) through Google's APIs, only to carry out tasks the owner asks for.

How data is used and stored

  • Data is processed on the owner's own server. Access tokens are stored only on that server.
  • To answer requests, relevant content may be sent to the AI model providers the owner has chosen.
  • Data is not sold, shared with third parties for advertising, or used for any purpose other than serving the owner.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
